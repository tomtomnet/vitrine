# vitrine's logo

`vitrine.svg` is the app's icon: installed as the hicolor `vitrine` icon,
which the app loads at run time for its windows and About box
(`Icons::app()`); it is not built into the program.

It shows QEMU's emu, Kew, on his Q behind a glass pane. It is derived from
"Kew the Angry Emu" by Benoît Canet, published by the QEMU Community
(https://lists.gnu.org/archive/html/qemu-devel/2012-02/msg02865.html; QEMU's
`ui/icons/qemu.svg`), under CC BY 3.0
(https://creativecommons.org/licenses/by/3.0/). The file lists its changes.
`vitrine.svg` is under CC BY 3.0 as well, not under vitrine's
GPL-2.0-or-later.

vitrine is not affiliated with or endorsed by the QEMU project.
